# StreamCut

Локальная Windows-мастерская для длинных стримов: просмотр исходника, поиск моментов по русской речи и изображению, ручная доводка и фоновый экспорт. Интерфейс — PySide6 / Qt Widgets; плеер — libmpv. Базовая конфигурация работает на CPU без CUDA и платных API.

Версия **0.2.0**. Проверенные возможности и границы проверки перечислены в [docs/STATUS.md](docs/STATUS.md). Полный шестичасовой анализ пока не проходил длительный приёмочный прогон.

## Запуск

В подготовленном репозитории два варианта:

- `Запустить StreamCut.cmd` — запуск из изолированного Python-окружения.
- `dist/StreamCut/StreamCut.exe` — переносимая сборка. Перемещайте **всю** папку `dist/StreamCut`, включая `_internal` и `StreamCut-worker.exe`.

Для просмотра и ручного экспорта Ollama и Whisper не нужны. Нажмите «Открыть видео» или перетащите файл. Проект создаётся автоматически; путь показан в строке состояния и подсказке имени исходника. «Проекты» открывает папку с `project.sqlite`.

Добавьте момент, укажите границы и папку экспорта. «Экспортировать и далее» ставит снимок текущих настроек в очередь и выбирает следующий непроверенный момент. Готовые файлы появляются после успешного завершения FFmpeg. Исходник не изменяется.

Чтобы сохранить часть длинного видео, нажмите «Всё видео» над таймлайном. Задайте начало/конец клавишами I/O, полями времени или синими ручками. Меню «Обрезать» также позволяет оставить часть до/после курсора, первую/вторую половину или разделить выбранный клип. «Вписать» показывает весь выбранный диапазон.

Вверху параметров клипа выберите «Оригинал» или «Shorts 9:16». По умолчанию оригинал экспортируется **без повторного сжатия**, с исходным разрешением и частотой кадров. Границы такого экспорта зависят от ключевых кадров; для покадровой точности выберите «Точный монтаж». Shorts и другие преобразования требуют перекодирования: Full HD становится 1080×1920, HD — 720×1280. В инспекторе до экспорта показаны итоговое разрешение и сохраняемая длительность. Режим «Как в исходнике» сохраняет также 4K; уменьшение выбирается явно.

## Подготовка с нуля

Windows x64, Python 3.13, Git. В PowerShell из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe scripts/setup_media.py
.\.venv\Scripts\python.exe -m streamcut
```

Те же действия выполняет `scripts/install.ps1`. Если выполнение PowerShell-скриптов ограничено системой, используйте команды выше. Скрипт подготовки скачивает FFmpeg/FFprobe из BtbN и libmpv из shinchiro, проверяет контрольную сумму релизного архива, если она предоставлена GitHub, и сохраняет фактические URL/SHA256 в `vendor/manifest.json`. Для BCJ2 используется локальный `7zr.exe` с официального сайта 7-Zip. Глобальный PATH не меняется.

Ollama установите с [официального сайта](https://ollama.com/), запустите её, затем откройте в StreamCut раздел «Модели». Проверьте соединение, размер нужного тега и скачайте модель. Отдельно скачайте Whisper small. После подготовки сети не требуется. Подробности — [docs/MODELS.md](docs/MODELS.md).

## Работа

- Space — воспроизведение/пауза, I/O — границы, ←/→ — перемотка на 5 секунд.
- Стрелки ↑/↓ при фокусе списка — выбор момента; Ctrl+Enter — экспорт и далее.
- «Удалить», Delete или контекстное меню удаляют выбранный момент. Ctrl+Z возвращает его; после перезапуска доступно «Правка → Восстановить удалённый момент». Очередь и готовые файлы сохраняются.
- Ctrl+Z / Ctrl+Shift+Z — отмена/повтор правок, создания, удаления и разделения; в текстовых полях работают обычные текстовые команды.
- Потяните ленту кадров — она движется под курсором и перематывает видео. Белый курсор и линейку можно перетаскивать отдельно. Колесо меняет масштаб вокруг мыши; ползунок снизу и общий таймлайн перемещают видимый участок.
- Миниатюры и волна появляются постепенно, сохраняются в кэше проекта и остаются на экране при перемотке. Устаревшая подгрузка отменяется. Миниатюры с ≈ показывают ближайшие ключевые кадры; после отпускания мыши плеер выполняет точный переход.
- Щелчок по реплике — переход; двойной — исправление текста. Поддерживается импорт SRT/VTT.
- В меню «Вид» можно скрыть расшифровку и инспектор. Панели и размер окна сохраняются.
- «Фрагменты» собирает клип из диапазонов исходника в хронологическом порядке. «Вырезать внутри» исключает участок. Для сборки нужен точный режим экспорта.
- Форматы 9:16, 16:9, 1:1, размытый фон и «вебкамера + игра» настраиваются в инспекторе. Кадрирование ручное, геометрия обновляется в плеере сразу. Дополнительная кнопка предпросмотра рендерит точный результат со звуком и субтитрами.
- Очередь позволяет отменить, повторить ошибку, приостановить запуск следующих заданий, открыть файл или папку.

Быстрый экспорт копирует потоки, зависит от ключевых кадров и не применяет обработку звука. Для точных границ, кадрирования, субтитров и составных клипов используйте перекодирование.

## Данные и восстановление

Каждый проект содержит SQLite со снимками состояния, `cache/` для воспроизводимых временных данных и `evidence/` для сохранённых кадров. Состояние сохраняется автоматически и после законченных блоков анализа. Незавершённые экспорты восстанавливаются в очередь. Открытый проект защищается файлом блокировки от второго окна приложения.

Перемещённый исходник можно переподключить через меню «Проект». Размер, время изменения и выборочные хеши проверяются перед повторным использованием. Изменённый файл нужно открыть новым проектом. Очистка кэша сохраняет расшифровку, правки, свидетельства, исходник и пользовательские результаты. Самостоятельное удаление папки проекта также не удаляет внешний исходник или экспорты в другой папке.

Исходные медиа, веса, кэш, SQLite, окружение и сборки исключены из Git. В GitHub отправляется код и документация.

## Проверки и сборка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\ruff.exe check .
.\.venv\Scripts\python.exe -m scripts.gui_smoke "D:\Видео\Запись.mp4"
.\.venv\Scripts\python.exe -m scripts.gui_startup "D:\Видео\Запись.mp4"
.\.venv\Scripts\python.exe -m scripts.keyboard_smoke
.\.venv\Scripts\python.exe -m scripts.editor_smoke "D:\Видео\Запись.mp4"
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm StreamCut.spec
.\.venv\Scripts\python.exe -m scripts.release_smoke "D:\Видео\Запись.mp4"
.\.venv\Scripts\python.exe -m scripts.process_smoke "D:\Видео\Запись.mp4"
```

GUI-проверки открывают настоящее окно, создают тестовые проекты и экспорты в игнорируемой папке `local/`. `gui_startup` рассчитан на исходник длиннее четырёх минут. `scripts/benchmark.py` измеряет первые 10 минут; `scripts/ai_smoke.py` использует результат этого замера; `scripts/visual_smoke.py` проверяет кадры около часа записи без расшифровки. Эти сценарии явно ограничены тестовыми диапазонами; само приложение не ограничивает длину видео или число результатов.

`scripts.release_smoke` открывает оконный exe с отдельными тестовыми проектами в оригинальном и вертикальном формате, проверяет кадр плеера, разрешение экспорта, миниатюры и аудиоволну. После проверки восстанавливает настройки окна и последний пользовательский проект. Отчёт сохраняется в `local/release-editor-02`.

Для ручной диагностики: `StreamCut.exe --project <папка проекта> --smoke-output <папка отчёта>`. Режим открывает проект, проверяет плеер и таймлайн, сохраняет JSON и декодированный кадр, затем закрывается. Используйте отдельный тестовый проект с курсором у начала выбранного момента. Сборка изолирует свой PATH, чтобы сторонние DLL инструментов не подменяли системную ICU Windows.

Архитектура: `domain.py` — правила и типы; `editing.py` — обратимые операции; `storage.py` — SQLite; `media.py` — FFmpeg и экспорт; `preview_cache.py` — отменяемая подгрузка кадров и аудиоволны; `worker.py` — отдельный процесс анализа; `ollama.py` — локальный API и валидация; `tasks.py` — фоновые задачи Qt; `widgets.py` — виртуальный список и таймлайны; `ui.py` — взаимодействие пользователя.

Сторонние компоненты: [THIRD_PARTY.md](THIRD_PARTY.md).
