# Изменения

## 0.3.1

- Исправлена подготовка Whisper при оборванной загрузке: HTTPS вместо native Xet, докачка, три попытки и проверка SHA256 каждого файла.
- Незавершённый кэш Hugging Face больше не считается установленной моделью; готовые файлы используются повторно.
- Прогресс Whisper в мегабайтах, показ ожидания сети и постоянные журналы фоновых задач в `%LOCALAPPDATA%\StreamCut\logs`.
- Фоновая задача, завершившаяся без результата, показывает ошибку и путь к журналу.

## 0.3.0

- Windows x64 установщик для текущего пользователя, ярлыки и удаление с сохранением данных.
- Первый запуск: автоматическая подготовка Ollama, Whisper small, Qwen и NVIDIA-библиотек без Python/CUDA Toolkit.
- Whisper: Авто / CPU / обязательная NVIDIA CUDA, выбор вычислительного типа, возврат на CPU при ошибке CUDA в автоматическом режиме.
- Проверенные SHA256 компонентов, возобновление прерванных загрузок, повторное использование установленных моделей.
- Проверка реального распознавания и ответа Qwen с показом фактического CPU/GPU.
- Лицензия GPLv3 и включённые уведомления сторонних компонентов.
- Пользователь подтвердил успешный полный анализ шестичасового стрима и экспорт найденных моментов в 0.2.

## 0.2.0

- Удаление и восстановление моментов, отмена создания/разделения.
- Монтаж всего исходника, обрезка до/после курсора, сохранение половины.
- Оригинал без повторного сжатия по умолчанию; разрешение исходника и Full HD Shorts.
- Перемотка перетаскиванием, масштаб под мышью, постепенный кэш кадров и аудиоволны.
