# StreamCut 0.3.0 — установщик и NVIDIA / CPU

Локальный Windows-видеоредактор для длинных стримов: поиск моментов, ручная обрезка, Shorts и экспорт без повторного сжатия в исходном формате.

## Установка

1. Скачайте **StreamCut-Setup-0.3.0-windows-x64.exe** и запустите.
2. После установки нажмите **«Подготовить нейросети»** в открывшемся мастере.
3. Дождитесь установки недостающей Ollama, загрузки Whisper/Qwen и проверки моделей. Затем откройте видео и запустите анализ.

Python, командная строка и отдельный CUDA Toolkit не нужны. Первая подготовка требует интернета и обычно загружает 4–7 ГБ. Рекомендуются Windows 11 x64, 16 ГБ ОЗУ и 20 ГБ свободного места. После подготовки анализ работает локально. Редактор и ручной экспорт доступны также без нейросетей.

## Что нового

- Whisper автоматически выбирает NVIDIA CUDA или CPU. Есть ручные режимы CPU и обязательной CUDA.
- При ошибке CUDA в автоматическом режиме текущий блок повторяется на CPU без дублирования частичных реплик.
- Qwen использует GPU через Ollama. Для Whisper на AMD/Intel используется CPU. Нужен актуальный драйвер NVIDIA; драйвер установщик не меняет.
- Единый мастер подготовки с проверкой реальных ответов моделей. Установленные компоненты и модели сохраняются.
- Возобновление загрузок, проверенные SHA256, согласованные версии CUDA/cuDNN; библиотеки не добавляются в глобальный PATH.
- Установка для текущего пользователя, ярлыки и удаление с сохранением проектов, моделей и экспортов.
- Лицензия GNU GPLv3 и включённые уведомления сторонних компонентов.

Сохранены возможности 0.2: удаление/восстановление моментов, обрезка всего видео и его половин, живой Shorts-предпросмотр, разрешение исходника по умолчанию, перемотка перетаскиванием и кэш таймлайна.

## Файлы

- **Setup … .exe** — основной рекомендуемый вариант установки.
- **StreamCut-0.3.0-windows-x64.zip** — portable: распакуйте всю папку, запустите StreamCut.exe.
- **StreamCut-0.3.0-source.zip** — исходники со скриптами сборки и лицензией.
- **SHA256SUMS.txt** — контрольные суммы файлов.

Установщик не подписан коммерческим сертификатом: Windows может показать предупреждение о неизвестном издателе. Скачивайте файлы из этого релиза и сверяйте SHA256.

## Проверки и границы

45 автотестов, настоящий Whisper/Qwen на CPU, загрузка Whisper в пустой кэш через упакованный процесс, Windows-загрузка согласованных NVIDIA DLL, просмотр и Shorts в готовом exe с очищенным PATH без Python. Пользователь подтвердил полный шестичасовой анализ и успешный экспорт в 0.2.

Установщик проверен реальной установкой в папку с кириллицей, запуском установленной программы и удалением. Проекты и пользовательские файлы после удаления сохраняются. Portable-архив прошёл проверку CRC.

Физическая RTX 5060 на машине сборки отсутствует, поэтому скорость GPU-инференса на ней ещё не измерена. Точный экспорт пока использует libx264 CPU, не NVENC. Данные старых проектов открываются через «Проекты» и не объединяются автоматически.
