# Локальные модели

Whisper запускается самим приложением через faster-whisper / CTranslate2 небольшими блоками по пять минут. По умолчанию устройство выбирается автоматически: NVIDIA CUDA при наличии совместимого оборудования и библиотек, иначе CPU INT8. На CUDA приоритет — float16, затем int8_float16/float32 согласно возможностям устройства. Есть ручные режимы CPU и обязательной CUDA. Ошибка CUDA при загрузке или выполнении в режиме «Авто» приводит к повтору всего текущего блока на CPU; частичные реплики не сохраняются. Завершённые блоки и ручные правки сохраняются. В обязательном режиме CUDA ошибка явно останавливает задачу.

Модель по умолчанию — мультиязычная **small**, язык — русский. Автоопределение языка выбирается в настройках; используется задача transcribe, а не перевод. Включены VAD, временные отметки слов и запрет автоматической загрузки весов во время самого анализа.

Первый запуск предлагает единый мастер: проверка установленной Ollama, её установка при отсутствии, загрузка Whisper и Qwen, CUDA-библиотек только при обнаруженной NVIDIA, затем настоящая проверка моделей. Мастер повторно доступен из «Справка → Подготовка нейросетей…» и «Модели». Все устанавливаемые компоненты указаны заранее. OllamaSetup и Windows-колёса NVIDIA закреплены по версии и SHA256; незавершённые загрузки продолжаются через HTTP Range. DLL сохраняются в каталоге пользователя, системный CUDA Toolkit и глобальная настройка PATH не требуются. Драйвер NVIDIA автоматически не устанавливается.

Для CTranslate2 4.8.4 используются cuBLAS/CUDA 12.9 и cuDNN 9.10.2.21 — та же версия, что у DLL-загрузчика в Windows-колесе CTranslate2. CUDA 12.8, с которой собрано Windows-колесо, поддерживает архитектуру Blackwell. Версия 0.3.1 проверена на физической RTX 5060 8 ГБ: Whisper small выполняет распознавание CUDA/float16, Qwen3.5:4b отвечает на GPU. AMD/Intel для Whisper используют CPU; ускорением Qwen управляет Ollama.

Whisper small/medium загружаются через обычный HTTPS без native Xet. Ревизии и контрольные суммы каждого файла закреплены в `assets/whisper-manifest.json`; доступны докачка и три попытки при сетевом сбое. Готовые файлы старого кэша используются повторно, неполный снимок не считается установленной моделью. Проверенные модели хранятся в `models_dir/streamcut-whisper-small` или `models_dir/streamcut-whisper-medium`. Журнал автоматической подготовки: `%LOCALAPPDATA%\StreamCut\logs\worker-prepare.log`.

Whisper medium доступна как дополнительный вариант, но её скорость и память на целевом ноутбуке ещё не измерены. Скачивание моделей выполняется отдельно в разделе «Модели». Там же можно выбрать папку и проверить распознавание первых 30 секунд выбранного файла. Музыка, имена и одновременно говорящие люди могут давать ошибки. Тайминги помечены как приблизительные.

faster-whisper 1.2.1 проверен с PyAV 16.1.0. PyAV 19 удалил используемый faster-whisper аргумент metadata_errors; поэтому в зависимостях явно установлен диапазон av >=16.1,<17. Python менять не потребовалось.

Текстовый и визуальный анализ выполняет **Qwen3.5 4B** через Ollama. На машине разработки проверен тег `qwen3.5:4b`, размер около 3,32 ГБ, возможности completion/vision/tools/thinking. Альтернатива — `qwen3.5:2b`; можно выбрать другой установленный совместимый тег. Сведения о доступных тегах: [официальная библиотека Ollama](https://ollama.com/library/qwen3.5). Перед скачиванием приложение запрашивает актуальный манифест и показывает размер. Установленные пользовательские модели не удаляются и не заменяются.

Адрес по умолчанию — http://127.0.0.1:11434. Для анализа используются ограниченный контекст 8192, структурированный JSON, существующие идентификаторы реплик/кадров и проверка ответа Pydantic. Неверный ответ повторяется один раз, после чего этап останавливается с сохранением завершённых блоков. При сохранении записывается digest использованной модели; он входит в ключ кэша.

Тяжёлые стадии идут последовательно: Whisper освобождается перед текстовой моделью; затем обрабатываются изображения. Для CPU обычный режим использует четыре потока. Есть тихий режим и выбор числа потоков. Экспорт имеет отдельную управляемую очередь и использует libx264 CPU, а не NVENC.

Визуальный режим выключен по умолчанию. Подробный режим последовательно проверяет выборки по три кадра. Экономный сначала редко покрывает исходник, затем уточняет предложенные области с шагом пять секунд. Нет общего лимита кадров. На общей шкале отмечаются фактически проверенные точки; это не утверждение о проверке каждой секунды. Видимые свидетельства сохраняются отдельно от удаляемого кэша. Поиск без расшифровки поддерживается.

Одиночные кадры могут пропускать быстрые события, а модель — выдумывать объяснения. Визуальная схема требует отдельного описания того, что видно на изображении, но это не устраняет ошибки. Проверяйте кадры и видео. Оценка модели не является вероятностью популярности.

Для освобождения памяти можно выгрузить выбранную модель в разделе «Модели». Автоматически выгружаются только модели, использованные текущей задачей приложения. Глобальные настройки Ollama не изменяются.
