# Локальные модели

Whisper запускается самим приложением через faster-whisper / CTranslate2, CPU INT8, небольшими блоками по пять минут. Модель по умолчанию — мультиязычная **small**, язык — русский. Автоопределение выбирается в настройках; используется задача transcribe, а не перевод. Включены VAD, временные отметки слов и запрет автоматической загрузки весов во время анализа.

Whisper medium доступна как дополнительный вариант, но её скорость и память на целевом ноутбуке ещё не измерены. Скачивание моделей выполняется отдельно в разделе «Модели». Там же можно выбрать папку и проверить распознавание первых 30 секунд выбранного файла. Музыка, имена и одновременно говорящие люди могут давать ошибки. Тайминги помечены как приблизительные.

faster-whisper 1.2.1 проверен с PyAV 16.1.0. PyAV 19 удалил используемый faster-whisper аргумент metadata_errors; поэтому в зависимостях явно установлен диапазон av >=16.1,<17. Python менять не потребовалось.

Текстовый и визуальный анализ выполняет **Qwen3.5 4B** через Ollama. На машине разработки проверен тег `qwen3.5:4b`, размер около 3,32 ГБ, возможности completion/vision/tools/thinking. Альтернатива — `qwen3.5:2b`; можно выбрать другой установленный совместимый тег. Сведения о доступных тегах: [официальная библиотека Ollama](https://ollama.com/library/qwen3.5). Перед скачиванием приложение запрашивает актуальный манифест и показывает размер. Установленные пользовательские модели не удаляются и не заменяются.

Адрес по умолчанию — http://127.0.0.1:11434. Для анализа используются ограниченный контекст 8192, структурированный JSON, существующие идентификаторы реплик/кадров и проверка ответа Pydantic. Неверный ответ повторяется один раз, после чего этап останавливается с сохранением завершённых блоков. При сохранении записывается digest использованной модели; он входит в ключ кэша.

Тяжёлые стадии идут последовательно: Whisper освобождается перед текстовой моделью; затем обрабатываются изображения. Обычный режим использует четыре потока CPU. Есть тихий режим и выбор числа потоков. Экспорт имеет отдельную управляемую очередь.

Визуальный режим выключен по умолчанию. Подробный режим последовательно проверяет выборки по три кадра. Экономный сначала редко покрывает исходник, затем уточняет предложенные области с шагом пять секунд. Нет общего лимита кадров. На общей шкале отмечаются фактически проверенные точки; это не утверждение о проверке каждой секунды. Видимые свидетельства сохраняются отдельно от удаляемого кэша. Поиск без расшифровки поддерживается.

Одиночные кадры могут пропускать быстрые события, а модель — выдумывать объяснения. Визуальная схема требует отдельного описания того, что видно на изображении, но это не устраняет ошибки. Проверяйте кадры и видео. Оценка модели не является вероятностью популярности.

Для освобождения памяти можно выгрузить выбранную модель в разделе «Модели». Автоматически выгружаются только модели, использованные текущей задачей приложения. Глобальные настройки Ollama не изменяются.
